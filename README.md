# Clinic Management System

A C-based clinic management project developed as part of ITI Embedded Systems training.

## Overview

This project provides a simple console-based clinic management system implemented in C. It focuses on core programming concepts such as data structures, functions, input handling, and basic record management.

## Project Contents

- `C-Project.c` — Main C source code for the clinic system.
- `STD_TYPES.h` — Common standard type definitions used by the project.
- `code vid.mp4` — Project demonstration video.
